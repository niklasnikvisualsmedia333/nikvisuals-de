# Design reference — Keravonos to NikVisuals v2

Reviewed 2026-09-12: Keravonos uses a dark, high-contrast canvas; Montserrat-style bold grotesk typography; large statement hierarchy; rounded green calls to action; substantial media panels; alternating section colour; and package rows that make dense information quick to scan.

## Patterns adapted

- Large, tight display type and short explanatory copy.
- Distinct visual modules instead of one continuous neutral editorial surface.
- Strong image crops paired with graphic number/label treatments.
- Clear numbered focus rows, bolder contrast sections, and a contact form integrated into the page flow.
- Lightweight image and CTA movement only; reduced-motion mode removes it.

## Not copied

No Keravonos text, logo, typography files, imagery, package structure, customer quotes, navigation, layouts, or brand green. NikVisuals remains substantially shorter and never makes its historical media clients appear to be AI-consulting references.

## NikVisuals v2 tokens

- Cream `#f7f3eb`, ink `#17191d`, electric blue `#425bf4`, acid lime `#c9ff38`, soft violet `#eee9ff`.
- Local system grotesk stack headed by Avenir Next where available; no external font request.
- Full-width sections, `1280px` content maximum, rounded pills for actions and deliberate asymmetric media.
